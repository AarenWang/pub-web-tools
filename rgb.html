4. 核心原理解析：RGB 光学加色 vs CMYK 印刷减色

为什么屏幕上的鲜艳色彩在 PDF/X 印刷交付时需要转换为 CMYK？

ISO 15930 (PDF/X) 色彩管理基础
RGB 加色模型 (Additive) 发光体

以黑屏 (0,0,0) 为起点，通过红、绿、蓝光子叠加产生新颜色。光线越叠加能量越高：

• R + G = Yellow (黄光)
• G + B = Cyan (青光)
• R + B = Magenta (品红光)
• R + G + B = White (纯白光)
CMYK 减色模型 (Subtractive) 反光油墨

以白纸为起点，油墨作为“滤光器”吸收特定波长的光。每多叠一层油墨，反射回人眼的光就越少：

• C(青墨) = 吸收红光 (-R)
• M(品红墨) = 吸收绿光 (-G)
• Y(黄墨) = 吸收蓝光 (-B)
• C + M + Y + K = 实地黑 (吸收全光谱)
色域差异与互逆对称性 互补对称

观察上方麦克斯韦色三角形可以发现：**RGB 的二次混合色恰好是 CMY 的主原色**，而 CMY 两两混合又还原出 RGB。

由于物理油墨纯度限制，CMYK 印刷色域小于 RGB 屏幕色域（尤其是高饱和荧光绿、亮蓝），因此在导出 PDF/X 印刷文件时必须嵌入 ICC 配置文件进行色域映射。
